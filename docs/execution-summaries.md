# 执行速览摘要

[← 返回中文 README](../README_zh-CN.md) · [English README](../README.md)

放大 Workflow 后点击右上角“执行速览”。Agent 保存输出后，服务端在独立后台队列中生成短摘要，页面每两秒更新等待/生成/完成/失败状态。“查看原文”保留原有的前 1,000 字预览。

- 沿用本项目“询问这个科研项目”所选解说 Agent 的 Harness、网关、model 和推理设置。请先在该模块配置可用的解说 Agent。
- 每次摘要是全新的只读调用，不复用或修改问答会话、问答历史，也不会修改科研文件或调度流程。仅向隔离工作区提供这次完整保存的输出，不附带其他项目文件。
- 提示词要求约 100–200 字中文，保留关键结果、数值和未完成事项。摘要由模型生成，仍需以原文为准；异常冗长回答最多保留 300 字。
- 摘要会产生额外模型调用和费用。全局摘要队列一次执行一项，单项超时三分钟；科研 Agent 不等待摘要完成。
- 结果存于项目的 `runtime/execution-summaries`，按调用标识和输出内容哈希复用。刷新页面不会重复调用模型；历史输出在打开速览时补生成。
- 失败不会自动反复调用模型；调整解说配置后可点击“重试摘要”。重启前遗留的等待/生成状态在再次查看时恢复。已完成摘要不会仅因更换解说模型而重新生成。

摘要服务不可用、配置无效、网关失败或超时均不改变科研执行状态；界面显示具体错误并保留原文入口。
