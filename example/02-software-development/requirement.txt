请在当前 workspace 中实现一个可运行的 Node.js 命令行待办事项工具，不引入第三方运行时依赖。

功能要求：
1. node cli.mjs add "事项内容"：添加事项并输出稳定、唯一的 ID；拒绝空白内容。
2. node cli.mjs list：按创建顺序列出事项，展示 ID、内容和完成状态。
3. node cli.mjs done <id>：将已有事项标记完成；重复完成操作保持幂等，未知 ID 明确报错。
4. node cli.mjs remove <id>：删除已有事项；未知 ID 明确报错。
5. 数据跨 CLI 进程持久保存。通过 TODO_DATA_FILE 环境变量指定数据文件，未设置时使用 workspace 中的 todos.json；文件损坏时给出清晰错误，不覆盖原数据。无效命令和无效参数以非零退出码结束。
6. 编写 README 说明运行方式；使用 Node.js 内置测试框架测试上述功能，测试使用独立临时目录，不触碰用户真实数据。
